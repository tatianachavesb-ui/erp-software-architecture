# Introducción y Objetivos

## Objetivo del Sistema

El objetivo del sistema ERP es integrar y gestionar los procesos de negocio de una empresa de repostería mediante una plataforma centralizada que permita optimizar las operaciones de compras, inventario, ventas y administración.

## Requisitos de Negocio del Módulo de Compras

- Registrar productos.
- Registrar proveedores.
- Crear órdenes de compra.
- Consultar historial de compras.
- Comparar cotizaciones de proveedores.
