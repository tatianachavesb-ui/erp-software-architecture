# Restricciones de Arquitectura

## Tecnologías Seleccionadas

- Backend: Java con Spring Boot.
- Frontend: React.
- Base de datos: PostgreSQL.
- Diagramación: PlantUML.
- Control de versiones: GitHub.

## Restricciones

- El sistema debe ser accesible desde un navegador web.
- La información debe almacenarse en una base de datos relacional.
- El desarrollo seguirá principios de arquitectura de software y metodologías ágiles.
